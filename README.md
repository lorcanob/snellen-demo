# Snellen screening toy: web demo

This repository only holds the published web demo. It is rebuilt automatically from
the main (private) project, so changes made here are overwritten.

Screening toy only, not a medical test. Everything runs in the visitor's browser; no
camera video is uploaded.

The letters use Optician Sans by ANTI Hamar and Fabio Duarte Martins, under the SIL
Open Font License 1.1 (see `dist/fonts/OFL.txt`).
